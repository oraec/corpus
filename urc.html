This tool checks the encoding of Unicode hieroglyphs according to our guidelines Recommendations for encoding Egyptian hieroglyphs in Unicode published by ORAEC. If you use code points that not respresent a real character, this tool notices the questionable codepoint and replace it with the correct one.
